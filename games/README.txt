Progman31lua games folder
=========================

Program Manager's Games group shows the shortcuts in this folder.

Put a folder in here for each game, with a shortcut to it inside:

    games\One Must Fall 2097\One Must Fall 2097.lnk
    games\Raptor\Raptor.lnk
    games\Steam\MegaRace.url

Windows shortcuts (.lnk) and Internet shortcuts (.url, as Steam and other
launchers make them) are both picked up, in this folder or in folders up
to four levels down. Each becomes an item named after the shortcut, with
the shortcut's icon. Running the item opens the shortcut.

The group is brought up to date each time Program Manager starts: items
for shortcuts that are gone are removed, new ones are added. Items you add
to the Games group yourself are left alone.
